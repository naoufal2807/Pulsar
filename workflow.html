📈 Data Flow

INPUT

Raw CSV/Parquet Files

36+ rows, 8 columns

→

OUTPUT

Clean Data + Insights

Quality Score, Rules, Recommendations

Processing Steps:
  1. Sample 10% of data (1,000+ minimum rows)
  2. Discover patterns: formats, ranges, distributions
  3. Expand validation to 100% of data
  4. Infer context: data type, purpose, quality tier
  5. Calculate quality score (0-100%)
  6. Detect anomalies: outliers, shifts, contextual
  7. Analyze root causes (with LLM support)
  8. Assess impact: business, operational, data quality
  9. Generate fix strategies with confidence scores
  10. Apply & validate fixes automatically
  11. Build reusable cleaning rules
  12. Learn preventive rules for future data
  13. Monitor patterns for drift
  14. Gate anomalies to prevent cascades
  15. Refine rules based on effectiveness

import polars as pl from pulsar.core.intelligence.small_world.isolator import Isolator from pulsar.core.intelligence.small_world.learner import Learner from pulsar.core.intelligence.small_world.expander import Expander from pulsar.core.intelligence.small_world.contextualizer import Contextualizer from pulsar.core.intelligence.small_world.analyzer import Analyzer # Week 1: INTELLIGENCE df = pl.read_csv("08_EWC2025_Country_Results.csv") isolator = Isolator() sample = isolator.extract(df, strategy='random') learner = Learner() patterns = learner.learn(sample) expander = Expander() expansion = expander.expand(df, patterns) contextualizer = Contextualizer() context = contextualizer.contextualize(df, patterns) analyzer = Analyzer() analysis = analyzer.analyze(patterns, context, expansion) print(f"Quality: {analysis.quality_score:.1%}")

🚀 Quick Start (3 Steps)

Step 1: Profile
Understand your data

Run: pulsar profile "your_file.csv" --verbose

Outputs: Quality score, strengths, weaknesses, recommendations

Step 2: Validate
Check against rules

Run: pulsar validate "your_file.csv" --rules rules.yaml

Outputs: Pass/fail status, anomalies detected, fixes applied

Step 3: Monitor
Track changes over time

Run: pulsar baseline "data.csv" --save

Then: pulsar baseline "data_new.csv" --compare baseline.json

Outputs: Drift score, columns affected, recommendations
